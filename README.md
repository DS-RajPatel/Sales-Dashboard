# Sales and Profit Analysis Dashboard

**Author:**  
Raj Patel

---

## 📊 Overview

This project presents a **Sales and Profit Analysis Dashboard** built using Flask, offering insights into business performance across customer segments, product categories, and regions during 2015. The dashboard features interactive filtering, enabling dynamic exploration of key metrics such as sales, profits, and discounts.

---

## ✨ Key Features

✅ Interactive dashboard with slicers for Product Category, Region, and Order Date  
✅ Visualization of sales trends, profit stability, and discount distribution  
✅ Focus on Small Business segment — the most profitable and highest-sales segment  
✅ Clear identification of potential over-discounting in Office Supplies  
✅ Actionable recommendations for refining strategies and improving profitability

---

## 🛠 Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML, CSS, JS (templates + static files)
- **Deployment:** Render (or other hosting platforms)

---

## 🔍 Main Insights

- **Small Business Segment** outperformed others in both sales and profit margins.
- **April 2015** showed a surprise sales surge, possibly due to seasonal or promotional factors.
- **Office Supplies** received 52.71% of total discounts, raising concerns about over-discounting.
- **Dynamic slicers** allow granular, on-the-fly exploration of data by category, region, and time.
- **Profit dips** observed in February and May, worth further investigation.
